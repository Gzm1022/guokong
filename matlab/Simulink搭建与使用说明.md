# Simulink 模型搭建与使用说明（MATLAB / Simulink 2024b）

本目录用一个脚本自动搭建两个 Simulink 模型，对应《过控提纲》的方法1、方法2：

| 模型文件 | 对应方法 | 结构 |
|---|---|---|
| `do_single_loop.slx` | 方法1 单回路PID | DO偏差 → PID → 鼓风机 → 供气 → 水体DO |
| `do_cascade.slx` | 方法2 串级PID | 外环DO(PI) → 内环供气流量(PID) → 鼓风机 → 供气 → 水体DO |

---

## 一、一键生成模型

1. 用 MATLAB 2024b 打开本文件夹 `matlab/`；
2. 打开 `build_simulink_models.m`，按 **F5（运行）**；
3. 当前文件夹会自动生成 `do_single_loop.slx` 与 `do_cascade.slx`；
4. 双击任一 `.slx` 打开模型，点工具栏 **▶ 运行**，双击 `Scope` 即可看到溶解氧 DO 响应曲线。

> 模型参数（与数值脚本完全一致）：
> 副对象 `G2(s)=1/(15s+1)`、纯滞后 `30s`、增益 `K1=4`、主对象 `G1(s)=1/(180s+1)`、DO 设定值 `2 mg/L`、仿真时长 `2400s`。

---

## 二、模型方框说明

**单回路（`do_single_loop`）**

```
SP(阶跃2.0) →(+/−)Err→ PID →(+)AddSec→ G2=1/(15s+1) → Delay(30s) → K1=4 →(+)AddPri→ G1=1/(180s+1) → DO
                ↑________________________________ 反馈 ________________________________________|
            Dsec(供气二次扰动)↑                                   Dpri(耗氧一次扰动)↑
```

**串级（`do_cascade`）**

```
SP →(+/−)Err1→ PIDout(主,PI on DO) →(+/−)Err2→ PIDin(副,PID on 流量) →(+)AddSec→ G2 → Delay → K1 → (+)AddPri → G1 → DO
        ↑__________ 主回路反馈(DO,慢) __________________________________________________________________|
                              ↑___ 副回路反馈(供气流量,快) ___|（取自 G2 输出）
```

- **Dsec**：二次扰动（供气母管压力波动/支路抢气），加在供气流量入口（`AddSec`）。
- **Dpri**：一次扰动（进水耗氧负荷突增），加在 DO 入口（`AddPri`）。
- 两个扰动 `Step` 模块的 **Final value 默认 = 0**（即不起作用，便于先看纯阶跃响应）。

---

## 三、复现三组实验

| 实验 | 操作 | 现象 |
|---|---|---|
| 设定值阶跃响应 | 两个 Step 扰动保持 0，直接运行 | DO 由 0 上升并稳定到 2 mg/L |
| **二次扰动**（串级核心优势） | 双击 `Dsec`，把 **Final value** 改为 `-0.18` | 单回路 DO 明显下陷(≈0.18mg/L)且恢复慢；串级几乎无波动 |
| 一次扰动 | 双击 `Dpri`，把 **Final value** 改为 `-1.0`（同时把 `Dsec` 改回 0） | 两者动态偏差相近（该扰动在副回路之外） |

> 扰动加入时刻由 Step 模块的 **Step time = 1200s** 决定。

---

## 四、控制器参数（PID Controller 模块内）

| 模块 | 形式 | P | I | D | N |
|---|---|---|---|---|---|
| 单回路 PID | PID | 0.70 | 0.0040 | 15.0 | 2 |
| 串级·主控制器 PIDout | PI(on DO) | 0.52 | 0.0034 | 20.0 | 2 |
| 串级·副控制器 PIDin | PID(on 流量) | 4.0 | 0.60 | 0 | 2 |

输出限幅均为 `[0, 1]`（执行器物理范围），抗积分饱和 = clamping。

> 关于 N：Simulink 连续 PID 模块的微分带宽较宽，在 30s 纯滞后下若用默认 N=100 会出现极限环；
> 故取 N=2（滤波时间常数 0.5s）。**本 Simulink 模型用于直观演示控制结构与抗扰行为；
> 报告中的定量性能指标（超调、调节时间、IAE 等）以数值脚本 `aeration_do_sim.m` / `.py` 为准**
> （两者采用步长 0.5s 的离散 PID，结果完全一致）。三套实现对“二次扰动抑制”的结论一致：
> 单回路最大偏差 ≈0.18 mg/L，串级 ≈0.007 mg/L。

## 五、手动搭建（不想用脚本时）

1. 新建模型，从库浏览器拖入：`Step`×3、`Sum`×(2或3)、`PID Controller`×(1或2)、`Transfer Fcn`×2、`Transport Delay`×1、`Gain`×1、`Scope`×1；
2. 按上面方框图连线（`Sum` 的符号：偏差用 `+-`，叠加扰动用 `++`）；
3. `Transfer Fcn`：分子 `[1]`，分母分别填 `[15 1]` 和 `[180 1]`；`Gain` 填 `4`；`Transport Delay` 的 Delay 填 `30`；
4. 双击 `PID Controller` 按上表填参数，勾选 Output saturation 限幅 `[0,1]`；
5. 模型配置 StopTime=2400，Solver 选 `ode45`，运行。
