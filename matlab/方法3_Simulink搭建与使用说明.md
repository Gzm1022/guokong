# 方法3 Simulink 搭建与使用说明

本文档用于手动搭建 **方法3：普通前馈 + 串级 PID 曝气 DO 控制** 的 Simulink 模型。  
该模型在方法2“串级 PID”的基础上增加前馈通道，将进水流量和污染物浓度作为可测扰动，提前补偿目标供气量。

---

## 零、一键生成模型

如果不想手动拖模块，可以直接运行脚本：

```text
build_method3_simulink_model.m
```

运行步骤：

1. 用 MATLAB 打开 `matlab/` 文件夹；
2. 打开 `build_method3_simulink_model.m`；
3. 按 F5 运行；
4. 脚本会自动生成：

```text
do_feedforward_cascade.slx
figures/do_feedforward_cascade_diagram.png
```

生成后双击该 `.slx` 文件，点击 Simulink 工具栏中的运行按钮，即可查看 Scope 和 To Workspace 输出。

## 一、方法3控制结构

方法3结构为：

```text
进水流量 Q、污染物浓度 C
        |
        v
耗氧负荷前馈模型 ---> 前馈供气量 q_ff
        |                    |
        |                    v
DO设定值 ---> DO外环PID ---> + ---> 目标供气量 ---> 供气流量内环PID ---> 鼓风机/阀门
   ^                                                                           |
   |                                                                           v
   +------------------------------- 好氧池 DO 对象 <---------------------- 实际供气流量
```

与方法2相比，方法3多了一个前馈补偿通道：

```text
Q、C -> 耗氧负荷估算 -> 前馈供气量 -> 与 DO 外环输出叠加
```

其中：

- DO 外环负责根据 DO 偏差进行反馈调节；
- 前馈模型根据进水扰动提前计算需要增加的供气量；
- 供气流量内环负责快速跟踪目标供气量；
- 前馈模型不可能完全准确，因此仍需要 DO 外环反馈消除误差。

## 二、模型参数

本模型参数与 `sim_method3_feedforward_cascade.m` 和 `python/sim_method3_feedforward_cascade.py` 保持一致。

### 2.1 被控对象参数

| 参数 | 数值 | 含义 |
|---|---:|---|
| `SP` | 2.0 | DO 设定值，单位 mg/L |
| `G2(s)` | `1/(15s+1)` | 鼓风机/阀门到实际供气流量 |
| `Delay` | 30 s | 供气到 DO 的纯滞后 |
| `K1` | 4 | 供气流量到 DO 的增益 |
| `G1(s)` | `1/(180s+1)` | DO 主对象 |
| 仿真时间 | 2400 s | StopTime |
| 扰动加入时刻 | 1200 s | Step time |

### 2.2 进水扰动参数

| 变量 | 初值 | 阶跃后 | 说明 |
|---|---:|---:|---|
| 进水流量 `Q` | 1.00 | 1.20 | 归一化进水流量 |
| 污染物浓度 `C` | 1.00 | 1.40 | 归一化污染物浓度 |

真实耗氧扰动：

```text
d_load = -[1.20 * (Q - Q0) + 1.60 * (C - C0)]
```

前馈估算模型：

```text
q_ff = q_base + [1.05 * (Q_meas - Q0) + 1.35 * (C_meas - C0)] / 4
```

其中：

```text
q_base = SP / K1 = 2.0 / 4 = 0.5
```

## 三、需要的 Simulink 模块

从 Simulink Library Browser 中拖入以下模块：

| 模块 | 数量 | 所在库 | 用途 |
|---|---:|---|---|
| `Step` | 4 | Sources | DO设定、进水流量Q、污染物浓度C、供气扰动/耗氧扰动 |
| `Sum` | 5 | Math Operations | DO偏差、前馈叠加、流量偏差、供气扰动叠加、耗氧扰动叠加 |
| `PID Controller` | 2 | Continuous | DO外环PID、供气流量内环PID |
| `Transfer Fcn` | 2 | Continuous | G2、G1 |
| `Transport Delay` | 1 | Continuous | 30s 纯滞后 |
| `Gain` | 4 | Math Operations | K1、Q系数、C系数、除以K1 |
| `Constant` | 2 | Sources | Q0、C0 或 q_base |
| `Sum` / `Add` | 若干 | Math Operations | 前馈模型内部加减 |
| `Scope` | 1-3 | Sinks | 显示 DO、供气量、控制量 |
| `To Workspace` | 1-3 | Sinks | 保存 DO、供气量等数据 |

如果希望模型更清晰，可以把前馈计算部分封装成一个 Subsystem，命名为：

```text
Feedforward_Load_Model
```

## 四、手动搭建步骤

### 4.1 搭建 DO 串级反馈主通道

先搭建方法2串级 PID 主体：

```text
SP -> Err1(+/-) -> PIDout -> AddFF -> Err2(+/-) -> PIDin -> AddSec -> G2 -> Delay -> K1 -> AddPri -> G1 -> DO
```

其中：

- `Err1` 的符号设为 `+-`，输入为 `SP - DO`；
- `PIDout` 为 DO 外环控制器；
- `AddFF` 用于叠加 DO 外环输出和前馈供气量，符号设为 `++`；
- `Err2` 的符号设为 `+-`，输入为 `目标供气量 - 实际供气量`；
- `PIDin` 为供气流量内环控制器；
- `AddSec` 的符号设为 `++`，用于叠加供气侧扰动；
- `AddPri` 的符号设为 `++`，用于叠加耗氧端扰动；
- `G2` 设置为 `1/(15s+1)`；
- `Delay` 设置为 `30`；
- `K1` 设置为 `4`；
- `G1` 设置为 `1/(180s+1)`。

主回路反馈：

```text
G1输出DO -> Err1负端
```

副回路反馈：

```text
G2输出实际供气流量 -> Err2负端
```

### 4.2 搭建前馈通道

前馈通道输入为进水流量 `Q` 和污染物浓度 `C`。

先用两个 Step 模块产生进水扰动：

```text
Q Step:
Step time = 1200
Initial value = 1.0
Final value = 1.2

C Step:
Step time = 1200
Initial value = 1.0
Final value = 1.4
```

前馈计算公式为：

```text
q_ff = q_base + [1.05 * (Q - 1.0) + 1.35 * (C - 1.0)] / 4
```

可以按下面方式搭建：

```text
Q -> Sum(Q-Q0) -> Gain(1.05) --\
                                Sum -> Gain(1/4) -> Sum(+q_base) -> q_ff
C -> Sum(C-C0) -> Gain(1.35) --/
```

其中：

```text
Q0 = 1.0
C0 = 1.0
q_base = 0.5
```

前馈输出 `q_ff` 接入 `AddFF` 的一个正输入端，与 DO 外环 PID 输出相加。

为了体现在线仪表测量滤波，也可以在 Q 和 C 后分别加入一阶惯性环节：

```text
1/(35s+1)
```

若只是课程演示，可以先不加测量滤波，模型结构更直观。

### 4.3 搭建耗氧负荷扰动通道

为了让被控对象受到真实进水负荷扰动，需要把进水负荷变化转换为 DO 侧负扰动：

```text
d_load = -[1.20 * (Q - 1.0) + 1.60 * (C - 1.0)]
```

搭建方法：

```text
Q -> Sum(Q-Q0) -> Gain(1.20) --\
                                Sum -> Gain(-1) -> AddPri
C -> Sum(C-C0) -> Gain(1.60) --/
```

该扰动接入 `AddPri` 的正输入端。由于前面已经乘以 `-1`，所以接入 `AddPri` 后表现为 DO 被消耗、出现下降。

### 4.4 添加供气侧扰动

供气侧扰动用于模拟母管压力波动或支路抢气，可选。

若需要保留与方法2一致的供气扰动接口：

```text
Dsec Step -> AddSec
```

建议默认设置为：

```text
Step time = 1200
Initial value = 0
Final value = 0
```

如果想观察供气侧扰动影响，可把 Final value 改为：

```text
-0.18
```

## 五、PID 参数设置

### 5.1 DO 外环 PID

方法3中，DO 外环只负责反馈微调，前馈已经承担主要扰动补偿，因此外环参数可比纯串级 PID 略小。

| 参数 | 数值 |
|---|---:|
| P | 0.26 |
| I | 0.0015 |
| D | 8.0 |
| N | 2 |
| 输出限幅 | `[-0.25, 0.25]` |

注意：方法3的 DO 外环输出是“反馈修正量”，不是完整目标供气量，因此可以允许其输出为正或负。

### 5.2 供气流量内环 PID

| 参数 | 数值 |
|---|---:|
| P | 4.0 |
| I | 0.60 |
| D | 0 |
| N | 2 |
| 输出限幅 | `[0, 1]` |

内环输出为鼓风机变频指令或空气阀门开度，必须限制在 `[0, 1]`。

在模型设置中：

```text
StopTime = 2400
Solver = ode45
```

如果模型中使用连续 PID Controller 模块，建议：

```text
Derivative filter coefficient N = 2
Anti-windup method = clamping
```

输出限幅：

```text
鼓风机/阀门指令 u: 0 到 1
目标供气量 q_sp: 0 到 1
```

## 七、推荐观察曲线

建议至少连接以下 Scope 或 To Workspace：

| 信号 | 说明 |
|---|---|
| `DO` | 溶解氧响应 |
| `q_ff` | 前馈计算得到的供气量 |
| `q_sp` | 叠加前馈和反馈后的目标供气量 |
| `air_flow` | G2 输出的实际供气流量 |
| `u` | 鼓风机控制指令 |
| `Q`、`C` | 进水流量和污染物浓度 |

重点观察：

- 扰动加入后 DO 是否下降；
- 加入前馈后目标供气量是否提前上升；
- 实际供气流量是否能跟踪目标供气量；
- DO 恢复时间是否短于普通串级 PID。

## 八、与方法2的区别

方法2串级 PID：

```text
DO偏差 -> 外环PID -> 目标供气量 -> 内环PID -> 鼓风机
```

方法3普通前馈 + 串级 PID：

```text
进水扰动 -> 前馈模型 -> 前馈供气量
                              +
DO偏差 -> 外环PID -> 反馈修正量
                              |
                              v
                         目标供气量 -> 内环PID -> 鼓风机
```

因此：

- 方法2对供气侧扰动抑制效果好；
- 方法3进一步改善进水耗氧负荷扰动下的快速性；
- 方法3的性能依赖前馈模型准确性，模型误差由 DO 反馈回路修正。

## 九、预期仿真现象

当 `t = 1200 s` 时，进水流量和污染物浓度上升，耗氧负荷增加。

普通串级 PID：

- DO 先明显下降；
- 反馈检测到 DO 偏差后才逐渐提高供气量；
- 恢复时间较长。

普通前馈 + 串级 PID：

- 前馈模型提前计算出更高供气需求；
- 目标供气量和鼓风机指令更早上升；
- DO 最低值更高，恢复时间更短；
- 控制能量略有增加。

可参考数值脚本结果：

| 控制方法 | 最低 DO / mg/L | 最大偏差 / mg/L | 恢复时间 / s | IAE |
|---|---:|---:|---:|---:|
| 串级 PID | 1.783 | 0.217 | 448.5 | 66.79 |
| 普通前馈 + 串级 PID | 1.818 | 0.182 | 240.0 | 36.48 |

## 十、报告可用结论

方法3在串级 PID 的基础上引入进水流量和污染物浓度前馈补偿。当进水耗氧负荷突增时，前馈通道能够在 DO 明显下降前提前提高目标供气量，使供气内环提前动作，从而减小 DO 下跌幅度并缩短恢复时间。由于前馈模型存在误差，系统仍保留 DO 外环反馈来消除稳态偏差和不可测扰动。因此，普通前馈 + 串级 PID 相比单纯串级 PID 具有更好的进水负荷抗扰动能力，但会带来略高的供气能耗。
